# 电影生成系统质量评审指南

## 一、核心评审原则

### 1.1 摄影决策优先于物体清单
**正确示例**：
```
使用85mm定焦镜头，机位略高于角色视线10度，营造温柔俯视感。
主体人物占画面中央60%，背景虚化至F1.8景深，确保注意力聚焦。
柔光从左侧45度照射，光比2:1，营造温暖氛围。
```

**错误示例**：
```
一个男人，穿着西装，站在办公室里，旁边有桌子、椅子、电脑、咖啡杯...
```

**评分要点**：
- 是否描述了"怎么拍"而非"拍什么"
- 是否有明确的摄影意图和情绪目标
- 是否避免了罗列式物体清单

## 二、运镜六要素检查

### 2.1 完整运镜描述模板
```json
{
  "camera_movement": {
    "start_position": "机位距主体3米，高度1.2米（略低于角色视线），45度侧方位",
    "movement_type": "缓慢推进（Dolly In）",
    "path": "直线推进路径，保持与角色正面15度夹角",
    "speed_curve": "ease-in-out曲线，前0.5s加速，中段匀速，后0.5s减速",
    "focus_shift": "起始焦点在角色双眼，推进过程中保持焦点跟随，景深从F2.8渐变至F1.4",
    "end_state": "机位距主体1米，形成特写构图，角色面部占画面70%",
    "constraints": "避免穿帮：画面左侧道具台始终保持出画，保持水平稳定器开启"
  }
}
```

### 2.2 评分检查清单
- [ ] **起始位置**：是否包含机位、高度、距离、角度
- [ ] **运动类型**：是否明确了推/拉/摇/移/跟/升/降/固定
- [ ] **运动路径**：是否描述了具体运动轨迹
- [ ] **速度曲线**：是否包含加减速策略
- [ ] **焦点变化**：是否说明了焦点转移和景深变化
- [ ] **结束状态**：是否描述了运镜终点的画面状态
- [ ] **约束条件**：是否说明了需要避免的问题

## 三、视觉层级与画面控制

### 3.1 主体占比约束
**正确做法**：明确主体占画面的百分比
```
- 远景：主体占画面10-20%
- 全景：主体占画面30-40%
- 中景：主体占画面50-60%
- 近景：主体占画面70-80%
- 特写：主体占画面80-95%
```

**错误做法**：无约束的模糊描述
```
"一个人在场景中"（没有说明占比）
```

### 3.2 最亮元素控制
每个镜头必须明确画面中最亮的元素位置：
```
"画面最亮点位于主角面部左侧高光区，亮度值约200cd/m²，
次亮点为背景窗户漏光，亮度值约120cd/m²，
确保观众注意力优先聚焦于主角面部"
```

### 3.3 色彩策略限制（3-5色原则）
**正确做法**：
```json
{
  "color_strategy": {
    "primary_colors": ["深海蓝 #1A3A52", "暖金色 #D4AF37", "象牙白 #FFFFF0"],
    "accent_color": "珊瑚橙 #FF6F61",
    "forbidden_colors": ["避免纯黑 #000000", "避免荧光绿"],
    "rationale": "深海蓝营造科技感，暖金色提供温暖点缀，珊瑚橙用于关键UI交互"
  }
}
```

**错误做法**：无限制的色彩堆砌
```
"五彩斑斓的、色彩丰富的、多种颜色的..."
```

## 四、负向提示词翻译机制

### 4.1 翻译原则
将"不要X"转换为"要Y"的正向描述

**示例**：
| 负向表达 | 正向翻译 |
|---------|---------|
| 不要杂乱 | 保持极简构图，移除所有非关键元素 |
| 不要暗淡 | 使用明亮的侧光，保持画面整体亮度在180-220cd/m² |
| 不要模糊 | 使用F8-F11光圈确保深景深，前景到背景均保持清晰 |
| 不要晃动 | 使用三轴稳定器，保持水平线稳定，运动速度控制在每秒30cm以内 |

### 4.2 评分要点
- 是否识别出所有负向描述
- 是否成功转换为可执行的正向约束
- 转换后的描述是否具有可测量性

## 五、must_preserve契约机制

### 5.1 跨镜头一致性契约
```json
{
  "must_preserve": {
    "character_appearance": {
      "主角李明": "27岁亚洲男性，短黑发偏分，戴银框眼镜，身高175cm，穿深蓝色衬衫配卡其裤",
      "标志特征": "左手腕戴智能手表，右手无名指戴银戒指"
    },
    "scene_elements": {
      "办公室": "现代简约风格，白色墙面，原木色家具，落地窗朝东",
      "不变道具": "桌上MacBook Pro 16寸、黑色马克杯、绿植小盆栽"
    },
    "color_scheme": {
      "locked_colors": ["#1A3A52", "#D4AF37", "#FFFFF0"],
      "lighting_tone": "5500K自然光，光比始终保持2:1-3:1"
    }
  }
}
```

### 5.2 检查要点
- [ ] 角色外貌是否逐镜头锁定
- [ ] 标志性特征（配饰、疤痕等）是否保持
- [ ] 场景关键元素是否一致
- [ ] 色彩方案是否跨镜头统一
- [ ] 光照风格是否保持连贯

## 六、避免词袋式堆砌

### 6.1 禁止使用的无效修饰词
❌ 以下词汇应被删除或替换为具体描述：
- "HDR"、"8K"、"Ultra HD"（这些是技术参数，不是创作指令）
- "史诗般的"、"震撼的"、"令人惊叹的"（主观感受词）
- "体积光"（除非明确描述光束路径和强度）
- "电影感"（应具体描述色调、构图、运镜）
- "高级感"（应描述具体视觉元素）

### 6.2 正确的替代方式
| 模糊词汇 | 具体描述 |
|---------|---------|
| "电影感" | "2.39:1宽银幕比例，使用电影级色彩分级：高光偏暖（6500K），阴影偏冷（4500K），对比度降至0.7营造柔和过渡" |
| "体积光" | "从画面左上角45度角斜射的平行光束，可见光路经过薄雾产生的丁达尔效应，光束宽度约30cm，亮度渐变" |
| "史诗" | "使用14mm超广角镜头，低机位仰拍，天空占画面70%，主体位于黄金分割点，营造宏大空间感" |

## 七、帧继承决策逻辑

### 7.1 必须不继承的情况
✅ **场景切换**
```
镜头1：室内办公室
镜头2：户外街道
→ 判定：不继承（场景完全不同）
```

✅ **角色变化**
```
镜头1：李明特写
镜头2：王芳特写
→ 判定：不继承（主体人物不同）
```

✅ **时空跳跃**
```
镜头1：白天
镜头2：夜晚
→ 判定：不继承（时间跨越过大）
```

### 7.2 可以继承的情况
✅ **连续对话**
```
镜头1：李明说话（中景）
镜头2：李明继续说话（近景）
→ 判定：继承（同一人物，时空连续）
```

✅ **视角切换**
```
镜头1：全景展示房间
镜头2：房间内物体特写
→ 判定：继承（场景未变，仅景别变化）
```

### 7.3 评分标准
- 场景切换检测准确率 > 95%
- 角色变化检测准确率 > 95%
- 继承比例应在30%-80%之间（避免全继承或全不继承）
- 必须提供每个决策的明确理由

## 八、多帧参考与降级策略

### 8.1 帧提取策略
当启用帧继承时，不应仅使用上一镜头最后一帧：

**推荐做法**：
```python
reference_frames = [
    "shot_N_frame_last.jpg",      # 上一镜头最后帧
    "shot_N_frame_middle.jpg",    # 上一镜头中间帧
    "default_reference.jpg"       # 默认参考图（降级保障）
]
```

**理由**：
- 最后一帧可能存在运动模糊、半遮挡、过曝等问题
- 多帧提供更稳定的视觉参考
- 默认参考图作为兜底保障

### 8.2 降级逻辑
```
如果 上一镜头帧可用 且 质量合格（清晰度>0.7, 曝光正常）：
    使用上一镜头多帧
否则如果 默认参考图存在：
    降级使用默认参考图
否则：
    不使用帧继承，完全重新生成
```

## 九、开幕式场景特殊优化

### 9.1 触发关键词
当用户输入包含以下关键词时，启用开幕式优化：
- "开幕式"、"开场"、"Opening"
- "序幕"、"Prologue"
- "第一幕"、"First Scene"

### 9.2 优化策略
针对第一个镜头（Shot 1）进行强化：

**会议讨论强化**：
```
- 增加会议轮次：3轮 → 5轮
- 提升质量阈值：0.75 → 0.85
- 强制包含"第一印象评估"维度
```

**视觉设计强化**：
```json
{
  "opening_optimization": {
    "visual_impact": "提升至最高优先级，确保画面具有强烈记忆点",
    "composition": "使用黄金分割+三分法则双重校验",
    "color_control": "限制为3种主色+1种accent色，强化品牌识别",
    "camera_work": "禁止复杂运镜，使用稳定镜头建立信任感",
    "duration": "延长至7-10秒（常规镜头5-7秒），给予充分展示时间"
  }
}
```

**prompt增强**：
```
在原有prompt基础上添加：
"这是整部影片的开场镜头，需要建立视觉基调和情感锚点。
画面必须简洁、有力、令人印象深刻。
避免信息过载，聚焦单一核心视觉元素。"
```

## 十、质量评审流程

### 10.1 评审步骤
```
1. 接收待评审内容（JSON格式）
2. 加载对应阶段的评审标准
3. 逐维度进行检查：
   - 结构化检查（必填项、格式规范）
   - 语义检查（描述质量、逻辑性）
   - 一致性检查（跨镜头对比）
4. 计算加权总分
5. 生成详细评审报告
6. 给出通过/不通过判定
```

### 10.2 评分公式
```
总分 = Σ(维度得分 × 维度权重)

通过条件：
- 总分 >= 阈值
- 所有维度得分 >= 0.4（避免严重偏科）
- 关键维度（weight > 0.3）得分 >= 0.6
```

### 10.3 评审报告格式
```json
{
  "pass": true,
  "score": 0.82,
  "threshold": 0.75,
  "dimension_scores": {
    "shot_variety": 0.85,
    "camera_movement": 0.90,
    "composition": 0.78,
    "visual_continuity": 0.80,
    "storytelling": 0.75
  },
  "detailed_review": "本次分镜设计整体质量优秀...",
  "issues": [
    "镜头3的运镜缺少速度曲线描述",
    "镜头7和镜头8之间的轴线可能存在问题"
  ],
  "suggestions": [
    "建议在镜头3添加ease-in-out速度曲线",
    "建议使用中性镜头过渡来避免轴线跳跃"
  ],
  "approval_reason": "分镜设计符合电影叙事规律，运镜设计完整且服务于情感表达，视觉连贯性良好，仅有小问题不影响整体质量"
}
```

## 十一、常见错误及扣分项

### 11.1 严重错误（单项扣30%+）
- ❌ 完全缺失运镜6要素中的任意3项
- ❌ 使用物体清单式描述，无摄影意图
- ❌ 场景切换时错误判定为帧继承
- ❌ 色彩方案超过8种主色（严重过载）
- ❌ 完全没有must_preserve契约

### 11.2 中等错误（单项扣10-20%）
- ⚠️ 运镜6要素缺失1-2项
- ⚠️ 负向提示词未翻译
- ⚠️ 主体占比未明确
- ⚠️ 使用了"电影感"、"HDR"等词袋词汇
- ⚠️ 帧继承比例异常（<20% 或 >90%）

### 11.3 轻微问题（单项扣5%以下）
- ℹ️ 运镜描述不够详细
- ℹ️ 色彩策略略显复杂（6-7种色）
- ℹ️ 构图描述缺少视觉引导线
- ℹ️ 角色一致性描述不够精确

## 十二、评审员工作守则

### 12.1 客观性原则
- 严格按照评审标准打分，避免主观偏好
- 相同问题在不同镜头中扣分力度保持一致
- 记录每个扣分点的具体理由

### 12.2 建设性原则
- 不仅指出问题，还要给出改进建议
- 建议应具体可执行，避免"提高质量"这类空话
- 优先指出影响最大的问题

### 12.3 上下文感知
- 考虑前后镜头的连贯性
- 理解故事背景和情感需求
- 区分"技术错误"和"风格选择"

### 12.4 输出规范
- 使用JSON格式输出，确保可被程序解析
- 详细评审意见使用markdown格式，提高可读性
- 问题和建议使用列表形式，清晰易读
